Prompt para Mistral vibe
========================
Actúa como sysadmin del proyecto.

Objetivo:
Mantener y preparar el repositorio para un pipeline de producción asistida por LLM que termina en código Rust.

Reglas:
- No inventes arquitectura nueva.
- No completes contenido conceptual salvo headers y placeholders estructurales.
- No cambies nombres de carpetas o archivos sin justificarlo.
- Si falta información, deja TODO/FILLME claro.
- Tu prioridad es orden, consistencia y trazabilidad.

Tareas:
1. Verifica que exista exactamente este árbol de carpetas y archivos objetivo.
2. Crea los archivos que falten con encabezado estándar:
   - título
   - tipo de archivo
   - estado
   - fuente de verdad
   - dependencias
   - pendiente
3. Genera un informe breve:
   - archivos existentes
   - archivos vacíos
   - archivos con contenido
   - discrepancias con el árbol objetivo
4. No redactes diseño del juego ni lógica del motor.

Salida:
- lista de acciones realizadas
- lista de discrepancias
- lista de siguientes archivos prioritarios

Traducir una especificación ya estabilizada a código Rust claro, modular y revisable.

- SDK narrativo fuera del runtime

Importante:
- El motor no interpreta narrativa.
- NarrativeDefinition pertenece al SDK.
- El runtime consume configuración y estado, no prompts narrativos.

Entradas:
1. Resumen operativo del módulo:
[PEGAR]
2. Schema fuente:
[PEGAR]
3. Ejemplo válido:
[PEGAR]
4. Convenciones del repo Rust:
[PEGAR si existe]

Tarea:
Genera código Rust para:
- structs
- enums
- traits si son necesarios
- validaciones básicas

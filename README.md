# Guiones - Herramienta de Construccion Narrativa

## Descripcion

Guiones es una herramienta disenada para facilitar el desarrollo de guiones y narrativas mediante la integracion de agentes de IA.

## Caracteristicas Principales

- Proyecto: Definicion del contexto general
- Personajes: Creacion y gestion de personajes
- Narrativas: Lineas generales de la historia
- Tramas: Composicion narrativa con Story Elements
- Estructura Narrativa: Organizacion en actos y escenas
- Agentes de IA: Asistentes especializados

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- react-dnd

## Instalacion

npm install
npm run dev

## Uso

1. Crear un Proyecto
2. Crear Personajes
3. Crear Narrativas
4. Construir Tramas
5. Validar y Refinar
